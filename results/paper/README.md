# Figures, tables and movies

Figure numbers follow the revised manuscript (1–27) and the supplement (S1–S11). These 38 figures contain 42 PDF graphic components. The figures.csv file records their filenames, original captions and SHA-256 checksums.

The tables.csv file indexes the 8 manuscript tables and 6 supplementary tables. The tables directory contains their typeset values, units and captions. The table_cells.csv file separates entries by block, row and cell, retaining LaTeX for mathematical symbols, units and significant digits. The two parts of table 3 have separate block numbers.

The movies.csv file gives the public YouTube link for each of the twelve supplementary recordings. Movie numbers match the supplement.

Comparisons with earlier experiments or simulations are credited in the paper and captions. The PDF figures are the authors' displays of the results.
